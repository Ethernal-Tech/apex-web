# frontend

- `src/swagger/apexBridgeApiService.ts` is generated by NSwag from `apexBridgeService.nswag`
  (the spec comes from web-api `npm run swagger:generate`). Why: hand edits are lost on the next
  regeneration.
- Settings come from `src/settings/appSettings_development.json` or `appSettings_production.json`,
  chosen by `NODE_ENV`. Why: a new setting needs a key in those two and in
  `appSettings_mainnet_example.json`, which documents the mainnet values.
- `config-overrides.js` adds Node polyfills (crypto, stream, buffer, ...) for webpack 5. Why: the
  Cardano serialization libraries break without them.
- Cardano wallets go through Mesh (`src/features`), EVM wallets through `EvmWalletHandler.ts`.
- The Nexus testnet chain ID is hardcoded as 9070 in `src/utils/chainUtils.ts`. Why: a local
  Nexus with another chain ID needs a local patch there, which must not be committed.
