# Efficiency journal

One row per task, written as the work happens. `Estimate` is the conventional (no Claude) effort,
written **before** the task starts. Tokens come from local transcripts (main session only unless
noted). Critic = findings total / accepted / rework prevented.
New rows are fragments, one file each in `docs/efficiency/journal.d/`; this file keeps its
header and the rows written before them (`journal.py render` prints both as one table).
